# 学习指南变化概览与导航：文档核对记录

日期：2026-10-10。应用基线：`ce8d205`。本轮属于学习资料的Supporting工作，只改变本地文档，不推进ES或修改业务设计。阅读入口：[学习导航](../learning/README.md)，导航列出全部33份正式指南。

## 范围与判断标准

用户希望全部学习指南更便于阅读，并了解还可以增加哪些学习辅助内容。本轮在33份指南增加“开始前／本片或专题改变／完成后与边界”，链接真实后续片；新增按六个业务模块组织的导航，补充当前状态与阶段编号说明。根README和写作规范增加入口及后续维护规则。12份历史验证记录只补回指南链接，原始结果、日志和数据不改。

最小充分检查是33份覆盖、前后变化准确、新增链接存在、历史证据与当前状态分开、既有用户修改保留。达到这些条件即结束；不为文档整理重跑数据库、缓存、MQ、浏览器或性能实验。

## 历史证据怎样使用

- 前后变化来源为各指南正文及对应验证记录，不把历史通过数当作本轮运行结果。
- MVP-4记录的是2026-09-24 SQLite非并发证据及当时MySQL待验状态；后续支付真实MySQL/MQ/Worker成果从专题和各阶段记录查阅。
- 6C-4仅选型及静态核对，没有独立验证文件；证据在[ADR 0001](../adr/0001-flash-sale-inventory-conditional-update.md)及6C-2/3记录。6C-5才正式切换，6D-2才落实HTTP临时5秒。
- 缓存4C、4I、4J只有实验记录，导航按真实材料链接，没有虚构缺失的指南。4J已补健康未命中共用名额，旧4E/4I缺口按阶段理解。
- Lua默认关闭、限尝试速率；搜索基线不是慢SQL优化，ES尚未实现。这些边界与当前项目总纲核对。
